Sources and method

  • Contract addresses come from the official Aero docs security page (Migration section). Legacy token, escrow and migration-veNFT addresses are read on-chain from the migration contracts (V2_TOKEN(), V2_ESCROW(), MIGRATION_TOKEN_ID()).
  • Upgraded = paidBasis() on each migration contract (total legacy amount deposited). Locked % = upgraded locks ÷ (upgraded locks + legacy escrow supply() still outside the migration veNFT). Liquid % = liquid upgraded ÷ (liquid upgraded + legacy supply outside the escrow; this includes tokens in pools and on exchanges).
  • On-chain timing: the migration contracts allow veNFT upgrades from MIGRATION_OPEN() = Oct 21, 6:34 PM EDT, and liquid / expired-lock upgrades from epochNext(MIGRATION_OPEN) = Oct 21, 8:00 PM EDT (Oct 22 00:00 UTC).
  • Rates and steps: aerodrome.finance/docs/upgrade, velodrome.finance/docs/upgrade, aero.xyz/aero-upgrade.
